# 🚗 WRONG WAY RUSH

高速道路を**逆走**し、対向車をよけ続けるノンストップ・ブラウザゲームです。速度は上がり続け、ギリギリですれ違うほどボーナスが入ります。

2D・TPS・FPS の 3 つの視点で遊べ、1 つのファイルでボタン切り替えもできます。

## 遊び方

ビルド不要です。HTML ファイルをブラウザで開くだけで動きます。

```text
wrong-way-rush/index.html
```

> [!NOTE]
> 3D 版は CDN から [three.js](https://threejs.org/) (r160) を読み込むため、インターネット接続が必要です。
> ブラウザによってはローカルファイルの動画再生が制限されるため、簡易サーバー経由での起動を推奨します。
>
> ```bash
> npx serve .
> # または
> python -m http.server 8000
> ```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 2D / TPS / FPS をボタンで切り替えられる統合版 |
| `gyakusou.mp4` | クラッシュ時のカットイン動画 |

## 操作方法

| 操作 | キーボード | タッチ |
| --- | --- | --- |
| 左右移動 | `←` `→` / `A` `D` | 画面の左半分 / 右半分をタッチ |
| 前後移動 | `↑` `↓` / `W` `S` | - |
| ターボ | `Space` | - |
| スタート・リトライ | `Space` / `Enter` / クリック | タッチ |
| 視点切替（統合版） | `V` | 画面上部の 2D / TPS / FPS ボタン |
| 車種切替 | `C`（解放後） | 画面左下のボタン |

## ルール

- 5 車線の道路を逆走します。対向車・トラック・バリア・工事区間をよけて走ります。
- 時間とともに速度が上がり続け、障害物の密度も上がります。
- 後半は自車を追尾してくる車が現れます。
- 障害物に接触するとゲームオーバーです。

### スコア

- 走行距離（速度）に応じて加算されます。
- **ニアミス**（すれ違いの隙間が約 14px 未満）でボーナスが入ります。隙間が狭いほど高得点で、連続すると **COMBO** で倍率が上がります。
- ハイスコアは `localStorage` に保存されます。画面右下のボタンでリセットできます。

### ターボ（3D 版・統合版）

- 1 回 2 秒の加速で、保有数は 3 回です。
- 使用後は 4 秒間のクールダウンがあり、連続使用はできません。
- 12 秒ごとに 1 回ぶん回復します。

### 車種

| 車種 | 解放条件 | 特徴 |
| --- | --- | --- |
| STANDARD | 最初から | 標準性能 |
| **PHANTOM X**（スポーツカー） | スコア 1000 到達 | 加速・旋回性能 UP、ハイビーム、ターボ 5 回 |

PHANTOM X のスポーツカーモデルは TPS 視点で確認できます（2D 視点では車体の色が変わるだけです）。

## 視点

| 視点 | 説明 |
| --- | --- |
| 2D | 見下ろし型のクラシックな画面 |
| TPS | 自車の後方から見る三人称視点 |
| FPS | 運転席からの一人称視点（自車は非表示） |

## 動作環境

- WebGL に対応したモダンブラウザ（Chrome / Edge / Firefox / Safari）
- キーボード、またはタッチ操作が可能なデバイス

## 使用技術

- HTML / CSS / JavaScript（ビルド不要）
- Canvas 2D API
- [three.js](https://threejs.org/) r160
