# 🚗 WRONG WAY RUSH

高速道路を**逆走**し、対向車をよけ続けるノンストップ・ブラウザゲームです。速度は上がり続け、ギリギリですれ違うほどボーナスが入ります。

2D・TPS・FPS の 3 つの視点で遊べ、PC でもスマートフォンでも 1 つのファイルでボタン切り替えやタッチ操作が可能です。

## 遊び方

ビルド不要です。HTML ファイルをブラウザで開くだけで動きます。

```text
wrong-way-rush/index.html

```

> [!NOTE]
> 3D 描画は CDN から [three.js](https://threejs.org/) (r160) を読み込むため、インターネット接続が必要です。
> ブラウザのセキュリティ仕様により、ローカル環境で直接開くとカットイン動画の事前読み込み（`fetch`）や音声再生が制限される場合があるため、簡易サーバー経由での起動を推奨します。
> ```bash
> npx serve .
> # または
> python -m http.server 8000
> 
> ```
> 
>

## 操作方法

| 操作 | キーボード | タッチ（モバイル） |
| --- | --- | --- |
| 左右移動 | `←` `→` / `A` `D` | 画面の左半分 / 右半分をタッチ |
| 前後移動 | `↑` `↓` / `W` `S` | 画面左下の `▲` `▼` ボタン |
| ターボ | `Space` | 画面右下の `TURBO` ボタン |
| スタート・リトライ | `Space` / `Enter` / クリック | 画面タップ |
| 視点切替 | `V` | 画面上部の `2D` / `TPS` / `FPS` ボタン |

## ルール

* 5 車線の道路を逆走します。対向車・トラック・バリア・工事区間をよけて走ります。
* 時間とともに速度が上がり続け、障害物の密度も上がります。
* 後半は自車を追尾してくる車が現れます。
* 障害物に接触するとクラッシュ演出が入り、ゲームオーバーになります。

### スコア・オンラインランキング

* 走行距離（速度）に応じてスコアが加算されます。
* **ニアミス**（すれ違いの隙間が約 14px 未満）でボーナスが入ります。隙間が狭いほど高得点で、連続すると **COMBO** で倍率が上がります。
* 自己ベスト（BEST）はブラウザの `localStorage` に保存され、待機画面の「ハイスコアをリセット」ボタンからいつでも初期化できます。
* ゲームオーバー後に `🏆 ランキング / 登録` ボタンを押すと、名前（最大 10 文字）を入力してオンラインランキングにスコアを登録し、全国のプレイヤーと上位スコアを競うことができます。

### ターボ

* 1 回 2 秒の加速で、初期保有数は 3 回です。
* 使用後は 4 秒間のクールダウンがあり、連続使用はできません。
* 12 秒ごとに 1 回ぶん回復します。

| 車種 | 解放条件 | 特徴 |
| --- | --- | --- |
| STANDARD | 最初から | 標準性能 |
| **PHANTOM X**（スポーツカー） | スコア 1000 到達 | 加速・旋回性能 UP、ハイビーム、ターボ 5 回、専用 BGM |
| ？？？ | スコア???到達 | ？？？ |

PHANTOM X のスポーツカーモデル及びシークレット車種は TPS 視点で確認できます（2D 視点では車体の色が変わります）。

## 視点
